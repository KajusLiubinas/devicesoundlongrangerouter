# SOUNDBEAM · P2P Audio Streaming

[![GitHub Pages](https://img.shields.io/badge/hosted-GitHub%20Pages-blue?style=for-the-badge&logo=github)](https://yourusername.github.io/soundbeam)

**Zero backend, pure P2P WebRTC audio streaming.**  
Point your phone browser to the URL and instantly see other devices.

## ✨ Features

- ✅ **Fully static** — runs on GitHub Pages, no server needed
- ✅ **Real-time device discovery** — see active peers automatically
- ✅ **Cyan/teal theme** — vertical-friendly mobile UI
- ✅ **Slide-to-execute** — satisfying touch gesture
- ✅ **MP3 properties panel** — filename, duration, size, bitrate
- ✅ **Top bar** — random username + live battery percentage
- ✅ **Easter egg** — tap anywhere (outside buttons) 5× to reveal fullscreen image
